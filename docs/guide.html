Patrik Components

Scriptless HTML chart & range-bar components — one shared rendering script.

patrik-components.js

Every page contains only markup and data-* configuration. All rendering logic and styling live in a single external file. To use the components on any page, drop in the relevant HTML block and load the script once:

<!-- once per page, near the end of <body> -->
<script src="patrik-components.js"></script>
The script auto-renders on page load. It finds every .patrik-radar-chart and .patrik-range-bar element and builds them from their attributes. No inline JavaScript needed.

1   Radar chart (performance octagon)

Single dataset

<div class="patrik-radar-chart"
     data-axes="LIGHTWIND,FREERIDE,FOIL,FREEFLY,WAVE,SURF,RACING,FREESTYLE"
     data-values="100,90,70,85,95,60,80,75"></div>

data-values map to data-axes by position. Values are 0–100. Add or remove axes freely — the octagon adapts to any number of axes.

Switchable datasets (dropdown)

Put a <select class="patrik-radar-select"> inside the chart. Each option's value is the comma list of values (same order as data-axes). The script wires up switching automatically.

<div class="patrik-radar-chart" data-axes="Lowend,Directness,Riding,Jumping">
  <select class="patrik-radar-select">
    <option value="100,70,100,90">4Wave FLOW HD</option>
    <option value="90,95,90,100">4Wave FLASH HD</option>
  </select>
</div>

2   Range bars (feel / rider goals)

A range bar shows a band (a range, not a single value) between two poles, with a title above and configurable colours. Two modes:

Two-pole mode

A label at each end; the band highlights data-min→data-max as percentages (0–100).

<div class="patrik-range-bar"
     data-title="Power delivery"
     data-left="Direct" data-right="Smooth"
     data-min="25" data-max="62"></div>

Scale mode

Evenly spaced stop labels beneath the bar. With data-scale-index, data-min/data-max are stop indexes (0-based) instead of percentages.

<div class="patrik-range-bar"
     data-title="Rider level"
     data-scale="Entry,Intermediate,Advanced,Pro"
     data-scale-index="true"
     data-min="1" data-max="3"></div>
<!-- band spans Intermediate → Pro -->

Range-bar attributes

AttributeDescription
data-titleSmall uppercase title above the bar.
data-left / data-rightEnd-pole labels (two-pole mode).

4   Notes

  • Load patrik-components.js once per page, even with many component blocks.
  • All colours have sensible defaults (teal #1a3a4a + lime #b4ff64); only set data-* colours to override.
  • To re-render after changing the DOM dynamically, call PatrikComponents.render() in the console / your own code.
  • Colours accept any CSS colour: hex, rgb(), rgba(), named.
